# GAMMA-Stash-Loot-Injector
Script to inject custom items into GAMMA's treasure manager i.e. stashes. Users must enter internal item name(s) and the item's corresponding rarity tier.

Note: This script was specifically created to add custom weapons and ammo to the stash loot pool. I know that some items, such as outfits/armor, have their own systems for spawning throughout the world - I don't know if they require this script or not as I haven't tested other item types.
